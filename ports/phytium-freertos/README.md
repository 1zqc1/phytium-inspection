# 飞腾 FreeRTOS 和 OpenAMP 接入说明

## 官方起点

先选择一套相互匹配的 Phytium Pi OS、内核、设备树、工具链和 Phytium FreeRTOS SDK。官方入口已经确认包含飞腾派 OpenAMP 配置、CPU3 从核目标、RPMsg 示例和设备树补丁，但具体版本仍需在实际 CEK8903 上验证。

推荐验证顺序：

1. 使用官方配置构建镜像和从核固件。
2. 验证 Linux remoteproc 能加载、启动和停止从核。
3. 运行官方 RPMsg 回环并保存日志。
4. 确认选定 UART 的控制器、pinmux、电平、时钟和 IRQ 可由从核独占。
5. 在从核和 STM32 间发送协议 V1 固定测试帧，核对字节序和 CRC。
6. 把 `common/src/controller.c` 接入从核任务，使用真实识别结果驱动状态变化。

## 任务划分

| 任务 | 职责 |
|---|---|
| RPMsg 接收任务 | 接收 Linux 的拍摄确认、识别结果和故障消息 |
| 工件调度任务 | 运行公共状态机、检查工件号和期限、产生动作授权 |
| UART 任务 | 与 STM32 交换协议帧，处理 CRC、序号、ACK 和完成反馈 |
| 看门狗和健康任务 | 100 ms 心跳起步，300 ms 无有效心跳时禁止新动作 |

RPMsg 收到数据不等于业务完成，UART ACK 也不等于机械动作完成。只有对应出口传感器反馈并由 STM32 上报 COMPLETE，当前工件才可结束。

## 版本记录

每次可复现实验必须保存 Pi OS 提交号、Linux 内核版本、设备树补丁、FreeRTOS SDK 分支和提交号、工具链版本、从核固件哈希及镜像哈希。不同分支的配置文件和补丁不能凭文件名混合使用。
